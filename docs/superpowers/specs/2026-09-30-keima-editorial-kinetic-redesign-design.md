# KEIMA 桂馬數位 Editorial Kinetic 網站重構設計規格

日期：2026-09-30<br>
狀態：設計方向已確認，待規格核准<br>
方向：A — Editorial Kinetic

## 1. 專案目標

將既有 KEIMA 桂馬數位單頁網站重構為具有明確品牌觀點、編輯式構圖與精準動態節奏的雙語品牌網站。品質目標不是模仿特定獎項網站，而是用可被 Awwwards、Webby Awards、FWA 類型評審檢視的標準，提升概念一致性、視覺工藝、互動敘事、可用性與技術完成度。

核心品牌命題：

> 跨越既有路徑，連結新的可能。<br>
> Strategy, creativity, and connections for what comes next.

## 2. 不可改變的內容約束

- 保留繁體中文與英文雙語版本。
- 保留單頁長卷軸結構。
- 保留已確認的品牌介紹、人物資訊、服務／方法、聯絡 Email 與版權資訊。
- 專案區只呈現目前網站已有且可確認的真實專案，不新增或改寫不存在的案例。
- 不恢復已明確移除的 `CREATOR ERP`、`CONSULTING`、`DIGITAL／數位實驗`、`Not every good move is a straight line` 等內容。
- Hero 不恢復已移除的 `STRATEGY / PROJECTS / CONNECTIONS / DIGITAL` 文字列。
- 不新增聯絡表單；商務聯繫維持 Email。
- 人物照片未提供前，不生成或使用假人像；人物區保留品牌化幾何展示位置。
- Footer 不恢復社群、法律與其他未提供資訊。

## 3. 設計概念

### 3.1 Editorial Kinetic

以高級編輯設計作為視覺骨架，使用強烈字級對比、精準網格、充分留白與黑色斜切路徑建立識別。動態只用來揭露內容、連接段落與表達「跨越既有路徑」，不做無意義的裝飾堆疊。

### 3.2 視覺語言

- 主色：品牌黑、暖白、KEIMA 青。
- 主形狀：桂馬移動所隱喻的斜向跨越、折線、切角與跳躍節點。
- 主構圖：非對稱編輯網格；每一區只保留一個主要視覺焦點。
- 主字體感受：中文清晰、穩重；英文具幾何與編輯感。英文大標可收緊字距，但不得犧牲辨識。
- 細節：細線、序號、節點、短標籤作為資訊節奏，不以大量框線或同質卡片填滿畫面。

## 4. 資訊架構與區塊設計

### 4.1 Header

- 固定於頁首，但視覺重量降低，避免與 Hero 競爭。
- 左側為正式 Logo lockup；中央或右側為主要段落導航；最右為語言切換。
- 桌機維持橫向結構；手機改為清晰可操作的精簡選單。
- 當前段落狀態使用青色線段或節點，不使用過度醒目的填色按鈕。

### 4.2 Hero — 品牌出場

- 以大型 KEIMA Logo／wordmark 為主視覺，品牌定位為副標。
- 黑色斜切區域與青色邊線從裝飾升級為全頁「路徑」語言的起點。
- 移除探索提示與已刪除的服務關鍵字列。
- 首屏需在桌機、平板與手機都能明確看見 Logo、品牌主張與下一段內容方向。

### 4.3 About — 品牌資訊

- 大型英文主張與中文品牌介紹形成橫向編輯閱讀節奏。
- 先呈現品牌資訊，再進入人物區；About 不放人物照片。
- 長文使用適當欄寬、段距與對齊，避免單一巨大文字框。
- 以細線和青色路徑節點連接下一區。

### 4.4 Approach — How We Move

- 與專案區建立明顯不同的視覺結構。
- 使用垂直步驟／路徑序列呈現 Strategy、Projects、Connections 對應的中文內容。
- 避免再次使用三張大型卡片；重點是方法的先後關係與移動感。
- 滾動時，路徑線與節點依序啟動，文字揭露節奏保持克制。

### 4.5 Projects — Currently in Motion

- 保留既有真實專案；不新增虛構專案。
- 每個專案配置大型品牌化幾何媒體區、專案序號、名稱、類型與既有說明。
- 桌機採編輯式交錯版面或大型索引式畫面，避免與 Approach 同樣的卡片排列。
- 幾何展示必須各自有差異，不能只是更換文字的同一模板。
- 手機改為易掃讀的垂直節奏，保留圖像比例與資訊階層。

### 4.6 Profile — 人物資訊

- 區塊序號調整為連續的 `04`。
- 人物照片／幾何展示位於左側，姓名、職稱與介紹位於右側。
- 姓名與職稱分為兩行，中文與英文各自符合語言習慣。
- 未提供照片前使用明確的品牌幾何展示，不顯示「照片待提供」等臨時製作文字。
- 尺寸需克制，人物介紹是主內容，不讓展示區占據整個視窗。

### 4.7 Contact — 商務聯繫

- 區塊序號調整為連續的 `05`。
- 使用深色收束整頁，主訊息與 CTA 保留足夠字距，禁止英文黏字。
- CTA 與 Email 都可直接操作；焦點狀態需清楚。
- 不加入表單或未提供的聯絡方式。

### 4.8 Footer

- 高度縮減，避免再次形成一個完整內容頁。
- Logo 尺寸清楚但不搶 Contact 主訊息。
- 中文版導航顯示中文，英文版顯示英文。
- 最下方固定呈現：`Copyright © 2026 桂馬數位股份有限公司 All Rights Reserved.`
- 不顯示社群、版權資訊提供、法律資訊提供等項目。

## 5. 動態系統

### 5.1 原則

- 動態必須支援閱讀順序、空間關係或品牌命題。
- 避免每個元素同時移動；每個視窗只安排一個主要動態事件。
- 使用 transform 與 opacity 為主，避免造成版面重排。

### 5.2 主要動態

- Hero：Logo 與品牌主張分層揭露，斜切路徑有極低幅度視差。
- 區塊標題：使用遮罩／裁切揭露，不以通用淡入取代所有動畫。
- About：青色路徑線隨滾動延伸，連接文案節奏。
- Approach：步驟節點依閱讀順序啟動。
- Projects：媒體圖形與文字在進入視窗時形成錯位後歸位；Hover 僅提供細微位移與對比變化。
- Contact：深色底以受控的水平或斜向 wipe 進場，CTA 線條隨焦點／Hover 延伸。
- 全頁：可加入細緻的滾動進度節點，但不得妨礙導航與閱讀。

### 5.3 動態降級

- `prefers-reduced-motion: reduce` 時停用視差、路徑繪製與大幅位移。
- 手機降低動態距離和同時執行的動畫數量。
- JavaScript 未執行時，內容仍需完整可見與可操作。

## 6. 響應式設計

- 桌機：以非對稱網格和寬幅留白呈現品牌張力。
- 平板：保留構圖關係，但縮小巨型字，避免切線與內容重疊。
- 手機：轉為單欄順序，重新編排而非單純縮小桌機版。
- 針對至少 375、768、1440、1920 px 寬度逐一視覺驗證。
- 長英文、中文標點、Email、導航和專案名稱不得溢出或黏字。

## 7. 無障礙與可用性

- 使用正確語意區塊、標題順序與可辨識連結名稱。
- 所有互動可由鍵盤完成，焦點樣式與品牌一致且清楚。
- 文字與背景維持足夠對比；青色不用於過小的低對比正文。
- 導航錨點考慮固定 Header 高度。
- 語言切換保留正確 locale 與目前閱讀位置（若技術上合理）。
- 裝飾圖形不干擾螢幕閱讀器。

## 8. 效能與技術品質

- 保持 Next.js 靜態輸出與 GitHub Pages 相容性。
- 優先使用 CSS／SVG 建立幾何視覺，避免不必要的大型影像。
- 控制 Client Component 與動畫函式庫使用範圍。
- 字型載入避免版面跳動，並提供可靠 fallback。
- Production build 必須成功；所有現有路由與語言版本可直接開啟。
- 驗證 console error、404 資產、內部連結、HTTPS 與自訂網域。

## 9. 評審級自我檢查標準

每輪修改都依以下五個面向檢查，直到不存在高優先問題：

1. **Concept / 原創概念**：每個視覺與動態是否都能回到「跨越既有路徑」。
2. **Craft / 視覺工藝**：字級、字距、網格、留白、對齊、線條與圖形是否精準一致。
3. **Story / 內容敘事**：品牌、方法、專案、人物、聯絡是否形成清楚遞進。
4. **Experience / 使用體驗**：導航、語言、響應式、鍵盤與 reduced-motion 是否完整。
5. **Execution / 技術完成度**：Build、效能、資產、跨尺寸和正式網域是否通過驗證。

「獎項級」在本專案中的完成定義：網站具有明確且一致的品牌概念、沒有顯著排版與互動缺陷、跨裝置體驗完整、動態有目的、內容真實、正式建置與部署可驗證。此目標不等同保證獲獎，最終獎項結果仍取決於外部評審與同屆作品。

## 10. 驗收條件

- Hero 的 Logo、品牌主張與黑色斜切構圖在各尺寸完整成立。
- About、Approach、Projects 三區在視覺結構上明確不同。
- 既有真實專案全部保留，且沒有虛構案例。
- Profile 的照片／展示區位於左側，姓名與職稱分行。
- Contact 英文 CTA 不黏字，Email 可操作。
- Footer 緊湊、Logo 比例正確、導航語言正確、版權文字正確。
- 中英文所有頁面沒有文字溢出、遮擋或錯誤換行。
- reduced-motion、鍵盤操作與可見焦點通過人工檢查。
- `npm run build` 成功，靜態輸出可由本機伺服器完整瀏覽。
- 正式部署後 `https://keima.tw` 與主要語言路徑可安全開啟。
