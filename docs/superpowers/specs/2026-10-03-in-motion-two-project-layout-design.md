# CURRENTLY IN MOTION 雙專案版面設計

日期：2026-10-03

## 目標

縮減 `CURRENTLY IN MOTION` 區域的垂直高度，讓一般桌機視窗能在單一畫面中辨識並完整瀏覽兩個進行中專案，同時保留 KEIMA 現有的編輯式排版、幾何圖像與黑／米白／青色品牌語言。

## 內容範圍

專案清單只保留：

1. `JOBSGAME` — `https://jobsgame.tw/`
2. `VIRTUAL VECTOR` — `https://virtual-vector.com/`

移除 `INDIE GUIDER` 與 `GAMECF`。中文版使用 Virtual Vector 官方網站提供的名稱「虛擬向量計劃」及標語「跨越次元，與你相遇。」；英文版使用同一專案名稱與忠實英文描述，不加入未經來源支持的服務內容。

## 桌機版面

- 區域標題、眉題與簡介保留，但縮短上下留白。
- 兩個專案改為上下兩列的橫向卡片。
- 每列左側為固定 `16:9` 的大型封面區，右側依序顯示編號、專案名稱、類別、簡介與外連箭頭。
- 兩張卡片權重相同，不設定主次專案。
- 封面尚未提供時，沿用品牌化幾何圖像；幾何圖像需針對 `JOBSGAME` 與 `VIRTUAL VECTOR` 分別設計。
- 以 1280×800 與 1440×900 桌機視窗為主要驗證尺寸，目標是在不裁切卡片主要資訊的前提下，於一個 viewport 內呈現標題與兩個專案。

## 響應式行為

- 平板保留橫向卡片，但縮小間距與文字尺寸。
- 手機改為單欄：16:9 封面在上、文字資訊在下。
- 封面在所有尺寸維持 `aspect-ratio: 16 / 9`，避免未來置入封面圖時被任意裁成直式或正方形。

## 互動與無障礙

- 有效 HTTPS 網址的整張卡片維持可點擊。
- 卡片保留清楚的焦點樣式、專案名稱與類別組成的無障礙名稱。
- 動態效果沿用目前的 reveal 與 hover 節奏，但縮短位移，避免緊湊版面產生跳動。
- `prefers-reduced-motion` 行為維持現況。

## 程式與資料調整

- 更新中英文 `site-content` 的專案資料與 `ProjectId` 型別。
- 更新 `ProjectArt`，移除不再使用的專案變體並加入 `virtual-vector` 幾何視覺。
- 重構 `ProjectList` 的卡片結構，以支援固定 16:9 封面與右側資訊欄。
- 只修改此區域所需的 section、motion 與 responsive 樣式；其他首頁區塊與導覽不變。

## 驗證

- 內容測試確認中英文皆只包含兩個指定專案、順序與網址正確。
- 元件測試確認產生兩張卡片、16:9 封面容器與 `virtual-vector` 變體。
- E2E／視覺驗證確認桌機單畫面呈現、手機單欄版面、兩個外連網址與鍵盤焦點均正常。
- 執行完整測試、lint 與 production build。

## 不在本次範圍

- 不新增或生成實際專案封面圖。
- 不修改其他首頁區域、文案、導航或頁尾。
- 不變更部署方式、網域或 HTTPS 設定。
